# 终端一条下载命令：v3.1.0-beta.1

需要Python 3.9+。下面是一条完整命令，可整体复制到终端；较长是因为安全校验逻辑直接写在命令里，未从网络下载脚本来执行。可审阅同版[scripts/download.py](../scripts/download.py)。

命令只下载固定GitHub Release的数据ZIP，核对固定SHA-256，检查路径/文件类型/重复项/大小，再解压到当前目录下新的ai-company-v3.1.0-beta.1。不会全局安装、登录、启员工或执行ZIP内容；同名目录存在会拒绝覆盖。
