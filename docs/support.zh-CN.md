# 能力与支持边界

| 能力/入口 | 本包实际状态 | 使用前条件 |
|---|---|---|
| 新项目蓝图、岗位/流程/支撑/表达预填 | 已有规则和模板；未作独立员工全流程现场验收 | 当前AI能读资料，未知事实和建议分开 |
| 单架构师＋单主动员工 | 当前运行规则基线 | 准确会话、工具能力、明确授权及真实握手 |
| Codex已有会话 | 内置CLI投递和本地记录关联工具 | 当前Codex提供queue命令及可读会话记录 |
| Antigravity已有会话 | 原生环境或官方Sidecar投递；协作式回复文件 | 宿主认证环境、准确UUID、短时绑定和写回复能力 |
| WorkBuddy/CodeBuddy实验入口 | 源码完整保留；路线暂停，非推荐新手入口 | 另行验证认证/worker/模型及费用；本发布不代为启用 |
| 多岗位 | 可规划职责与登记候选，不是自动调度器 | 独立岗位需要各自会话、权限和方向验证 |
| 合同检查器 | 可选只读结构/关联检查 | 不验证真实权限、质量或目标完成 |
| 监听/恢复模拟器 | 离线原型 | 不等于生产监督或通知服务 |
| Claude/Grok/其他软件 | 没有通用连接承诺 | 需要实际可用且经核实的适配器 |

协作式final文件是目标AI主动写出的最终记录，不是原生进程结束事件。握手仅证明该项目/方向/当前入口，不能继承到别人的电脑。

开发者曾在macOS指定会话完成有界通信及只读任务试点，用户也确认过ai-chat长期使用；这些证据不等于新项目从零启动、员工主动连续两合同或中断恢复全部验收。Windows/Linux完整应用集成未现场验证，Node单元测试也不证明跨软件可用。

费用由所选软件/账号决定。本项目不提供账号或模型额度，不承诺对所有人免费；更换API、账户或付费入口须明确决定。
