# 三种可复制的使用提示

以下提示交给你自己的项目AI；不会因出现在文档里而自动发消息或授权其他项目。

## 新项目

```text
使用 ai-company，你担任总架构师。先根据我的想法预填目标、验收、非目标、第一阶段、业务岗位、流程、共享支撑和输出要求。
项目位置未定时给建议，不要默认写进当前其他项目。未知事实标出，只集中问关键选择。
岗位先给最小配置；我确认实际会话与权限后再接入和下发首份有界合同。
```

## 已有项目

```text
使用 ai-company 接入当前项目。先读已有规则、README、计划与绑定，复用权威资料，不重新初始化或覆盖。
给出当前角色、目标、已验证能力、缺口和下一份有界任务草案；已有有效授权不要重复问。
```

## 中断后恢复

```text
按 ai-company 恢复当前项目。先读原绑定、任务和请求handle，查清哪些已完成、哪些仍不确定。
保留原state-dir与目标归属，续查原请求；不换ID重发，不把暂停当取消，不假称后台仍在运行。
给出当前事实和下一责任人，能在原授权内推进的步骤直接继续。
```
