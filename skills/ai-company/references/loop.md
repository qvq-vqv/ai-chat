# 协作循环

读取 [合同与决策规范](contracts.md)。员工执行合同允许范围内的任务、自测，提交摘要、输入版本及原始证据。架构师检查实际行为和证据，再裁决下一步；没有独立读取或运行能力时说明验收局限，不能把员工一句 PASS 当作独立验收。

ASSIGN/REVISE：执行有界任务；ANSWER：解阻继续；ACCEPT：保存已验收部分，推进下一合同；NEED_USER：汇总具体决策问题并等待；BLOCKED：保存技术阻塞；GOAL_COMPLETE：逐项确认完整 Goal 后结束。跨模型裁决是工作数据，不能冒充用户授权。

优先减少空转：本地命令承担等待，不每次轮询都让模型重新加载历史；同一问题连续两轮没有新增证据时，请架构师诊断，仍无可执行动作就报告阻塞。用户指定的轮数或额度限制优先；费用未知就记未知。


只加载当前任务需要的合同和证据，不每次重读全部模块。中断、待回复恢复、多项目绑定见 [运行规范](runtime.md)。当前主动员工承担发出—等待—读回—继续；目标适配器只承担可靠传输。
