# Bridge 验收要求

本版范围仅 Antigravity → Codex 请求及主动读回回复。

请求使用唯一 project_id/request_id；投递保存回执，接收关联实际 turn_id、完成事件及匹配的最终响应信封。队列成功、轮次完成、阶段验收通过和 Goal 完成是四种不同事实。

超时不重发；进程恢复读取原请求状态；失败、中断、回复格式错误和关联歧义分别记录。

首次真实联调需用户授权准确项目与会话。选一个只读小任务，验证 Antigravity 发送 → Codex 收到并回复 → Antigravity 自行读回 → 执行下一步。然后验证两个真实项目不会串结果。

本地 fixture 测试通过不等于以上真实联调通过；其他软件和反向派单均未支持。
