# 验证边界

v2 支持经授权的 CLI 投递，以及项目目录内的恢复状态写入。工具不直接修改 Codex 会话存储或读取凭证；消息通过参数数组传给 CLI，不作为 shell 代码执行。运行状态不能放入 CODEX_HOME，包括指向该目录的符号链接。

本版完成了功能测试与代码检查，未进行独立安全审计。详细范围见 [验证记录](references/validation.md)。

## v3 路由边界

路由器只读本地指定的 manifest 和端点配置，不联网、不执行第三方技能、不读取凭证。能力声明可由第三方提供，必须读实现并现场握手核实；CANDIDATE 不是认证或连通性证明。外部 manifest 不能冒充内置执行器，重复 ID 会拒绝。现有 Codex 脚本的权限与协议保持不变。

新协作式适配：Antigravity 使用本机原生 CLI 参数数组及项目内请求专属回复文件；WorkBuddy 使用固定官方 HTTPS 地址和用户配置的 OAuth 环境令牌，禁止重定向携带 Authorization。目标全局记录拒绝跨项目复用和未解决请求的重投；随机 token 用于请求关联，不是身份认证。目标 AI 写出的 final 记录不等于原生运行结束，不能自动识别全部软件中断。没有从本机软件存储提取凭证，也没有自动批准权限。
